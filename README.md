# Progetto Reti Logiche

## English Version

### Overview
This repository contains a digital logic design project implemented in VHDL. The project was developed, synthesized, and simulated using the Xilinx Vivado design suite. 

### Functionalities and Structure
* **Hardware Description:** The core logic of the system is written in VHDL (`project_reti_logiche.vhd`).
* **Simulation & Testing:** The repository includes simulation sources and testbenches (including `project_tb.vhd` and `generated_testbench.vhd`) to verify the functional correctness of the design.
* **Constraints:** Hardware constraints, such as clock definitions, are specified in `clock_c.xdc`.
* **Finite State Machine:** The system's behavior is driven by a Finite State Machine (FSM) architecture. 

### Documentation and Diagrams
* **Project Report:** Comprehensive details, specifications, and design choices are documented in the [Project Report](https://github.com/vcristiano2000/ProgettoRetiLogiche/blob/main/ProgettoRetiLogiche.derivables/ReportProgettoRetiLogiche.pdf).

## Versione Italiana

### Panoramica
Questo repository contiene un progetto di reti logiche digitali implementato in VHDL. Il progetto è stato sviluppato, sintetizzato e simulato utilizzando l'ambiente Xilinx Vivado.

### Funzionalità e Struttura
* **Descrizione Hardware:** La logica principale del sistema è scritta in VHDL (`project_reti_logiche.vhd`).
* **Simulazione e Testing:** Il repository include sorgenti di simulazione e testbench (tra cui `project_tb.vhd` e `generated_testbench.vhd`) per verificare la correttezza funzionale del design.
* **Vincoli:** I vincoli hardware, come le definizioni di clock, sono specificati nel file `clock_c.xdc`.
* **Macchina a Stati Finiti:** Il comportamento del sistema è gestito tramite un'architettura basata su Macchina a Stati Finiti (FSM).
